# 操作系统内存管理模拟器

## 项目概述
这是一个模拟操作系统内存管理的教学演示项目，实现了类Unix系统的文件管理功能，包括文件/目录的创建、删除、复制、移动等操作，并提供了图形化界面展示内存分配状态。

## 功能特性
- 模拟磁盘块分配与管理
- 支持类Unix文件操作命令(cd, create, delete, makdir等)
- 图形化展示内存分配状态
- 剪贴板功能实现文件复制粘贴
- 文件控制块(FCB)管理

## 快速开始
1. 确保安装Python 3.6+
2. 克隆本仓库
3. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
4. 运行主程序：
   ```bash
   python os_ui.py
   ```

## 使用说明
### 基本命令
- `cd [目录]`: 切换当前目录
- `create [文件名]`: 创建文件
- `delete [文件名]`: 删除文件
- `makdir [目录名]`: 创建目录
- `deldir [目录名]`: 删除目录
- `copy [文件名]`: 复制文件到剪贴板
- `paste`: 粘贴剪贴板内容

### 图形界面
主界面将显示当前内存分配状态和文件系统结构。

## 开发指南
项目主要模块：
- `disk.py`: 磁盘管理核心逻辑
- `os_ui.py`: 图形用户界面
- `terminal.py`: 终端模拟器
